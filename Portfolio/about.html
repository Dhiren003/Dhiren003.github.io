About me

Hey! I'm Dhiren. I build websites that load fast, work on every screen and are easy for clients to run.

For more than five years I've been building websites and online stores for businesses, mostly on Shopify and WordPress. I like owning the whole path from first layout to launch: custom themes and plugins, connecting services through APIs, and the performance and SEO work that keeps a site quick on a phone.

Day to day I track down stubborn bugs, keep code tidy for the next developer, and talk with clients in plain language about what they actually need. Git and GitHub are part of everything I do.

Outside client work, I've been spending my learning time on generative AI, from prompts and embeddings to retrieval and tool calling, so I can bring smarter features to the sites I build.
